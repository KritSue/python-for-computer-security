# Lab 02 — Password strength checker

This lab checks basic length and character variety on a made-up sample. It never sends or stores the input. Do not type a real password into a practice script or website.

Run `python examples/password_strength.py`. The example input is a placeholder. Improve it to ask for a sample phrase, then report length and whether it includes letters and digits. Do not call a password “secure” based only on these simple checks: real password security depends on uniqueness, length, storage, and resistance to guessing.

**Concepts:** strings, `len`, conditions, boolean expressions, and privacy-aware handling.
