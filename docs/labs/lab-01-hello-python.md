# Lab 01 — Hello Python

**Goal:** create and run a script. Open `examples/hello.py` in VS Code, read each line, then run `python examples/hello.py` from the repository folder.

Expected output:

~~~text
Hello, Python!
This is my first defensive security learning script.
~~~

**Try:** change the second message, add a third print, and run it again. If the terminal says it cannot find the file, check your current folder and the spelling of the filename.
