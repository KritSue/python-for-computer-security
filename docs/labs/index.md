# Labs

Work through these labs in order. They use short scripts, invented data, and the Python standard library. From the repository folder, run an example with `python examples/filename.py` (or `py` on Windows if that is your Python command).

| Lab | Build | Main ideas |
|---|---|---|
| 01 | Hello Python | print, running files |
| 02 | Password strength checker | strings, booleans, safe password concepts |
| 03 | IP address validator | exceptions, ipaddress |
| 04 | Security log parser | files, parsing, counts |
| 05 | Failed login counter | dictionaries, thresholds |
| 06 | SHA-256 file hash | files, binary data, hashlib |
| 07 | JSON event parser | JSON, validation |
| 08 | HTTP header inspector | local HTTP and response metadata |
| 09 | Simple socket client | TCP and localhost |
| 10 | Defensive monitoring mini project | combine safe parsing and summaries |

For labs 08 and 09, the companion example starts a tiny service bound only to `127.0.0.1`. Do not expose it to a network.
