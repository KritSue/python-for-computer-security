# Glossary

| Term | Plain-language meaning |
|---|---|
| Argument | Extra value given to a program when it starts |
| Boolean | A value that is either True or False |
| CSV | A simple text format for rows and columns |
| Exception | A report that a problem happened while code ran |
| Function | A named reusable set of instructions |
| Git | A tool that records changes to files over time |
| Hash | A fixed-size digest computed from data; not encryption |
| HTTP | Rules for requesting and returning web resources |
| IP address | A network address for an interface |
| JSON | A text format for structured objects and lists |
| Loop | Code that repeats instructions |
| Module | A Python file with reusable code |
| Port | A numbered endpoint associated with a network service |
| Regex | A pattern language for finding text |
| Scope | Where a variable name can be used |
| Set | A collection of unique items |
| Socket | A software endpoint for network communication |
| Terminal | An app where commands are typed as text |
| Tuple | An ordered group commonly treated as fixed |
| Variable | A name that refers to a value |
| Virtual environment | A project-specific area for Python packages |
